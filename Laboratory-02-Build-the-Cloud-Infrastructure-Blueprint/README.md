# Laboratory 02 – Build the Cloud Infrastructure Blueprint

## Mission Overview

In this laboratory activity, I investigated the basic components of cloud infrastructure using the KillerCoda Linux environment. The activity focused on understanding compute, storage, networking, and operating system resources and how they work together in cloud computing. I also researched AWS, Microsoft Azure, and Google Cloud Platform and documented my findings using Markdown.

## Objectives

* Understand the basic components of cloud infrastructure.
* Investigate the resources available in a Linux environment.
* Identify compute, storage, networking, and operating system resources.
* Compare similar services from AWS, Microsoft Azure, and Google Cloud Platform.
* Practice creating technical documentation using Markdown.
* Organize my laboratory outputs in a GitHub repository.

## Cloud Infrastructure Components

### Compute Resources

CPU and RAM provide the processing power and memory needed to run commands, programs, and services.

### Storage Resources

The Linux file system provides storage for files, applications, configurations, and other data.

### Networking Resources

Network interfaces and IP addresses allow the Linux server to communicate with other systems and online services.

### Operating System

Linux manages the server's hardware and software resources and provides the environment where commands and applications can run.

## Linux Commands Executed

The following commands were used to investigate the Linux environment:

```bash
uname -a
```

Used to check information about the operating system and kernel.

```bash
lscpu
```

Used to view CPU information and the number of CPU cores.

```bash
free -h
```

Used to check the available and total RAM.

```bash
df -h
```

Used to check disk space and mounted file systems.

```bash
hostname
```

Used to identify the hostname of the Linux server.

```bash
ip addr
```

Used to view network interfaces and IP addresses.
