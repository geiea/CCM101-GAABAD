# Checkpoint 3 – Identify Cloud Infrastructure Components

## 1. Compute Resources

**Example:** CPU and RAM

**Purpose:**
CPU and RAM are used to process commands and run programs in the Linux environment. The CPU handles the tasks, while RAM provides temporary memory for running applications.

**Importance in Cloud Computing:**
Compute resources are important because cloud applications need processing power and memory to work properly. These resources can also be increased or decreased depending on the needs of the application.

**Relation to KillerCoda:**
In KillerCoda, the Linux environment uses allocated CPU and RAM to allow us to run commands, programs, and other activities during the laboratory exercises.

---

## 2. Storage Resources

**Example:** Linux file system and directories

**Purpose:**
Storage is used to save files, programs, configurations, and other data inside the Linux environment.

**Importance in Cloud Computing:**
Storage is important because cloud systems need a place to keep user data and application files. It also makes it possible to access and manage data when needed.

**Relation to KillerCoda:**
In KillerCoda, we can create folders and files in the Linux environment. These files are stored in the system while we are working on our activities.

---

## 3. Networking Resources

**Example:** IP address and network interface

**Purpose:**
Networking allows the Linux environment to communicate with other computers and online services.

**Importance in Cloud Computing:**
Networking is important in cloud computing because cloud servers need to communicate with users, applications, databases, and other servers.

**Relation to KillerCoda:**
The Linux environment in KillerCoda is connected to a network, allowing us to use commands such as `ping`, `ip`, and `curl` to check and interact with network connections.

---

## 4. Operating System

**Example:** Linux

**Purpose:**
The operating system manages the computer's resources and provides the environment where commands and applications can run.

**Importance in Cloud Computing:**
The operating system is important because it provides the basic platform needed to run cloud applications and services. Linux is commonly used for cloud servers because it is reliable and flexible.

**Relation to KillerCoda:**
KillerCoda provides us with a Linux environment that we can access through a web browser. It allows us to practice Linux commands and learn how cloud-based systems are managed.
