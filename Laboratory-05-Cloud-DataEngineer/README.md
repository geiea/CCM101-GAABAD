# Laboratory 05 – Cloud Data Engineer

## Mission Overview

This laboratory activity focuses on deploying an S3-compatible object storage server using MinIO and Docker. The goal is to create a storage environment for a photo-sharing application where user-uploaded images can be stored in a cloud-based object storage system.

## Objectives

- Understand the different types of cloud storage.
- Deploy MinIO using Docker.
- Access the MinIO Web Console.
- Create an object storage bucket.
- Upload a sample file to the bucket.
- Document the cloud storage deployment process.

## Tools Used

- KillerCoda Playground
- Docker
- MinIO
- GitHub
- Web Browser
- Linux Command Line

## Skills Learned

- Using Docker to deploy cloud services.
- Working with environment variables.
- Using Linux commands.
- Accessing services through specific ports.
- Creating and managing object storage buckets.
- Uploading files to cloud storage.
- Documenting technical procedures using Markdown.
