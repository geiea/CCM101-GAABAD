# Cloud Platform Recommendation Challenge

## Client A – Startup Company

### Recommended Cloud Platform: Amazon Web Services (AWS)

Amazon Web Services (AWS) is recommended because it provides flexible and scalable services that are suitable for a startup with a limited budget. The startup can begin with smaller resources and increase them as the mobile application gains more users. AWS also provides many services that can support application development, storage, and databases. The startup could use **Amazon EC2** for computing, **Amazon S3** for storage, and **Amazon RDS** for database management.

---

## Client B – University

### Recommended Cloud Platform: Microsoft Azure

Microsoft Azure is recommended because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's existing technologies, making the migration easier to manage. The university can use **Azure Virtual Machines** for Windows-based workloads, **Microsoft Entra ID** for identity management, and **Azure Blob Storage** for cloud storage. This can help the university move selected services to the cloud while continuing to use its existing Microsoft environment.

---

## Client C – AI Research Company

### Recommended Cloud Platform: Google Cloud Platform (GCP)

Google Cloud Platform (GCP) is recommended because it has strong capabilities for Artificial Intelligence and Machine Learning workloads. It provides cloud computing resources that can support applications requiring high-performance computing. The company could use **Google Compute Engine** for computing, **Vertex AI** for AI and Machine Learning development, and **Google Cloud Storage** for storing datasets and research files. These services can help researchers develop, train, and deploy AI and ML applications.

---

## Client D – Global E-Commerce Company

### Recommended Cloud Platform: Amazon Web Services (AWS)

Amazon Web Services (AWS) is recommended because it provides highly scalable and highly available infrastructure suitable for a global e-commerce company. AWS has services that can distribute applications across different regions and automatically adjust resources according to demand. The company could use **Amazon EC2** for computing, **Elastic Load Balancing** for distributing traffic, and **Amazon S3** for storing website and application data. These services can help maintain application availability and support automatic scaling during periods of high customer demand.

| Business Requirement        | Recommended Platform        | Justification                                                                                                                                                          |
| --------------------------- | --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Startup Company**         | AWS                         | AWS offers a wide range of flexible and scalable services that can support startups with limited budgets and growing applications.                                     |
| **Enterprise Organization** | AWS                         | AWS provides a broad range of services, strong security features, and scalable infrastructure suitable for large organizations.                                        |
| **Microsoft Environment**   | Microsoft Azure             | Azure provides strong integration with Windows Server, Microsoft 365, and Active Directory, making it suitable for organizations already using Microsoft technologies. |
| **AI / Machine Learning**   | Google Cloud Platform (GCP) | GCP provides strong Artificial Intelligence and Machine Learning services that support the development, training, and deployment of AI applications.                   |
| **Kubernetes Deployment**   | Google Cloud Platform (GCP) | GCP offers Google Kubernetes Engine (GKE), a managed Kubernetes service designed for deploying and managing containerized applications.                                |
| **Global Web Application**  | AWS                         | AWS provides scalable and highly available infrastructure that can support web applications serving users from different parts of the world.                           |
