## Questions and Answers

### 1. Which cloud provider offers the broadest range of services?

Amazon Web Services (AWS) offers one of the broadest ranges of cloud services among the three major providers. It provides services for computing, storage, databases, networking, security, analytics, machine learning, and many other areas.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure best integrates with Microsoft technologies because it works closely with products such as Windows Server, Microsoft 365, and Active Directory. This makes Azure a suitable choice for organizations that already depend heavily on Microsoft's ecosystem.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud Platform (GCP) is particularly strong in Artificial Intelligence, Machine Learning, and Kubernetes. Its Google Kubernetes Engine (GKE) provides a managed Kubernetes environment, while Google Cloud also offers several tools for developing and deploying AI and ML applications.

### 4. Which cloud platform would you personally choose and why?

I would personally choose Google Cloud Platform (GCP) because I am interested in Artificial Intelligence, Machine Learning, and modern application development. Its Kubernetes services and AI/ML tools would provide useful opportunities to develop my cloud computing and technical skills.
