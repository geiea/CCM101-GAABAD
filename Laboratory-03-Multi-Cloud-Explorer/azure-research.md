# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides services for computing, storage, networking, databases, artificial intelligence, security, application development, and other business requirements. Azure supports both cloud-based and hybrid environments.

## Global Infrastructure

Microsoft Azure operates through a worldwide network of geographic regions and datacenters. Azure has more than 70 announced regions globally. An Azure region contains one or more datacenters connected through high-capacity and low-latency networks.

Many Azure regions also provide Availability Zones. These are separate groups of datacenters with independent power, cooling, and networking infrastructure. Availability Zones help organizations improve application availability and fault tolerance.

## Cloud Management Console

The Azure portal is a web-based unified console used to create, manage, and monitor Azure resources. Users can manage subscriptions, create resources, view services, monitor applications, and customize dashboards through the portal.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide virtual servers that can run Windows or Linux workloads in the cloud.

### 2. Azure Blob Storage

Azure Blob Storage is an object storage service designed for storing large amounts of unstructured data such as documents, images, videos, backups, and logs.

### 3. Azure Virtual Network

Azure Virtual Network provides networking capabilities that allow Azure resources to communicate securely with each other, the internet, and on-premises environments.

### 4. Microsoft Entra ID

Microsoft Entra ID is Microsoft's cloud-based identity and access management service. It helps organizations manage users, identities, authentication, and access to resources.

## Three Advantages

1. **Microsoft Integration** – Azure works closely with Microsoft technologies such as Windows Server, Microsoft 365, and Active Directory.
2. **Hybrid Cloud Support** – Azure provides services that help organizations connect on-premises systems with cloud resources.
3. **Global Infrastructure** – Azure has a large worldwide infrastructure with many regions and availability zones.

## Typical Enterprise Use Cases

- Microsoft application hosting
- Enterprise application migration
- Hybrid cloud environments
- Virtual machine hosting
- Data storage and backup
- Business applications
- Artificial intelligence and analytics
