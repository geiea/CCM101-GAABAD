# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud Platform (GCP), commonly called Google Cloud, is a cloud computing platform provided by Google. It provides services for computing, storage, networking, databases, artificial intelligence, machine learning, data analytics, and application development.

## Global Infrastructure

Google Cloud operates a global infrastructure made up of regions and zones. Google Cloud currently provides infrastructure across 43 global regions and 130 zones distributed across six continents. This infrastructure allows organizations to deploy applications in locations that can provide suitable performance, availability, and data residency.

## Cloud Management Console

The Google Cloud console is a web-based management interface used to manage Google Cloud resources and services. It provides tools for creating virtual machines, managing storage, configuring networks, controlling permissions, monitoring resources, and managing costs.

## Four Core Services

### 1. Compute Engine

Compute Engine provides virtual machines that organizations can use to run applications and workloads on Google's infrastructure.

### 2. Cloud Storage

Cloud Storage provides scalable object storage for storing data such as files, backups, media, and application data.

### 3. Virtual Private Cloud (VPC)

Google Cloud VPC provides networking capabilities for Compute Engine, Google Kubernetes Engine, serverless workloads, and other cloud resources.

### 4. Cloud IAM

Cloud Identity and Access Management (IAM) allows organizations to control who can access Google Cloud resources and what permissions they have.

## Three Advantages

1. **Strong AI and Machine Learning Capabilities** – Google Cloud provides infrastructure and services designed for AI, machine learning, and data processing.
2. **Global Network** – Google Cloud provides a global infrastructure across multiple regions and zones.
3. **Kubernetes Support** – Google Cloud provides Google Kubernetes Engine (GKE), a managed environment for running containerized applications.

## Typical Enterprise Use Cases

- Artificial intelligence and machine learning
- Big data analytics
- Website and application hosting
- Containerized application deployment
- Data storage and backup
- Global applications
- Software development and testing
