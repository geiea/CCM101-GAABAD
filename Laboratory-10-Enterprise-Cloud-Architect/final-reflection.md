# Final Reflection – The Enterprise Cloud Architect

This laboratory activity gave me a better understanding of how cloud infrastructure works and how different technologies are used together to build and manage a cloud-based system. Throughout this activity, I was able to deploy my own cloud storage platform using Nextcloud and MariaDB on an Ubuntu Server virtual machine through Oracle VM VirtualBox. I also learned how Docker and Docker Compose make it easier to manage applications and their services without having to configure everything separately.

One of the things I learned from this activity was how important proper configuration is when setting up a cloud environment. I had to make sure that the virtual machine was working correctly, that the network settings allowed me to access the application, and that the Nextcloud and MariaDB containers could communicate with each other. At first, some of these steps were challenging, especially when configuring the services and making Nextcloud accessible through my Windows browser. However, by following the instructions carefully and checking each step, I was able to get the system running successfully.

I also gained experience in securing and maintaining the server. I configured the UFW firewall to control incoming connections and learned why database services should not be unnecessarily exposed to external access. Another important part of the activity was creating a backup script using Bash and scheduling it with Cron. This helped me understand how automation can reduce the need for manual tasks and how regular backups help protect important data. To test data persistence, I restarted the Nextcloud containers and confirmed that my uploaded test file was still available afterward.

Overall, this activity helped me realize that building a cloud system involves more than simply installing an application. It also requires proper networking, security, storage management, backup procedures, and regular monitoring. I learned how each component contributes to keeping the system functional and reliable. Although I encountered challenges along the way, solving them helped improve my technical skills and gave me more confidence in working with Linux commands, Docker, and server administration.

If I were to improve this project in the future, I would focus on adding HTTPS for more secure access, storing backup copies in another location, and improving the backup process with additional verification. These improvements would help make the system more secure and reliable. In conclusion, this laboratory activity was a valuable hands-on experience because it allowed me to apply what I learned about virtualization, containerization, cloud computing, security, and automation in an actual working environment.
