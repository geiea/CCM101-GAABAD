# Security Audit Report

## 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving users and applications only the permissions they need to perform their tasks. This helps prevent unauthorized access and reduces the damage caused by compromised accounts.

## 2. Attack Surface

The attack surface is the collection of entry points that attackers could use to access a virtual machine. Open ports, running services, and exposed applications can increase the attack surface.

## 3. Default Deny Policy

A Default Deny policy blocks incoming traffic unless a specific rule allows it. This is safer because only necessary connections are permitted, reducing the risk of unauthorized access.
