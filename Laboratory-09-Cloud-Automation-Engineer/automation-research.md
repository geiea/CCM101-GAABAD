# Automation Research

## 1. Bash Script

A Bash script is a file containing Linux commands that can be executed together to automate tasks. The `#!/bin/bash` line, called the shebang, tells the operating system to use Bash to execute the script.

## 2. Variables

Variables store information, such as directory paths, that can be reused throughout a script. For example, `$BACKUP_DIR` allows us to change the backup folder in one place instead of editing every command that uses it.

## 3. Cron Job

A cron job is a scheduled task in Linux that runs automatically at a specified time or interval. It is useful in cloud operations because it can automate repetitive activities such as backups, system maintenance, and scheduled scripts.
